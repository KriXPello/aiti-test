# Подготовка и запуск

- установить зависимости `npm i`
- выполнить `npm run dev`

# Примечания к решению

- для входа использовать `username` и `password` любого пользователя отсюда: https://dummyjson.com/users 
  - пример: `emilys`, `emilyspass`
- url dummyjson API вшиты в код, т.к. в рамках тестового задания не вижу смысла выносить в .env (в реальном проекте такие ссылки вынес бы)
- токен авторизации хранится в localStorage/sessionStorage в зависимости от флага "запомнить меня". В реальном приложении токен  хранился бы в cookie и была бы реализована логика обновления токенов
